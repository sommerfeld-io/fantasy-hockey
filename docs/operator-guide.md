# Operator Guide

Checklist for whoever runs the pool: what to do, and when. There's no admin screen — every task here is a hand-edit of `fantasy-hockey.yml`, following the stop → edit → start protocol from the [results and playoffs runbook](recording-results-and-playoffs.md). This page just says *when* each task is due; that runbook has the exact YAML shape for results, matchups and set-opening.

An AI coding assistant (e.g. Claude Code) can draft the exact YAML edit for any row below — describe what happened ("round 1 is over, here's who won each series") and ask it to propose the diff against your data file.

To run the app on a Raspberry Pi behind the nginx proxy, start from the [example production compose](examples/docker-compose.yml). It is an example, not a supported deployment: its dummy `SESSION_SECRET` and Mailpit SMTP target are placeholders you must replace, and the data directory must be writable by UID 1000. Port 80 is the only port meant for the internet; the proxy answers `/metrics` with 404, and the app's 8080 is published on the host's loopback only. From the repo root: `mkdir -p docs/examples/data && sudo chown 1000:1000 docs/examples/data`, then `docker compose -f docs/examples/docker-compose.yml up -d`, and check that `curl -i localhost/login` answers 200 while `curl -i localhost/metrics` answers 404. Back up the data directory: it holds the pool's only state.

## Checklist

| When                                                                                | Task                                                                                                                                                                                       | Details                                                                                                                                                                           |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| First deploy, or a new season's fresh data file                                     | Set `SESSION_SECRET` (required) and, to send real login-code emails, the `SMTP_*` variables                                                                                                | [README Configuration](index.md#configuration)                                                                                                                                    |
| First deploy, or a new season's fresh data file                                     | A freshly bootstrapped file only has `season` and an empty `players:` list — hand-add `teams:`, `prediction_sets:` and `nhl_players:` (copy their shape from an existing season's file)    | —                                                                                                                                                                                 |
| A player joins or leaves the pool                                                   | Add/remove their entry under `players:`                                                                                                                                                    | There's no in-app account creation                                                                                                                                                |
| The regular season's playoff field is set                                           | Flip the `playoffcup` Prediction Set's `upcoming` to `false`                                                                                                                               | [Opening the playoff Prediction Sets](recording-results-and-playoffs.md#opening-the-playoff-prediction-sets)                                                                      |
| Round 1's real matchups are known                                                   | Record `playoff_matchups.r1`, then flip `r1`'s `upcoming` to `false`                                                                                                                       | [Playoff matchups](recording-results-and-playoffs.md#playoff-matchups)                                                                                                            |
| A later round's (round 2 / conference finals / final) matchups are known            | Record that round's `playoff_matchups` entries — it opens automatically, no `upcoming` flag needed                                                                                         | [Opening the playoff Prediction Sets](recording-results-and-playoffs.md#opening-the-playoff-prediction-sets)                                                                      |
| A result becomes official (division winner, trophy, series result, award finalists) | Record it under `results:` / `award_finalists:`                                                                                                                                            | [Results and award finalists](recording-results-and-playoffs.md#results-and-award-finalists)                                                                                      |
| You made a mistake recording a result                                               | Fix the value and restart — the Leaderboard recomputes from scratch every request                                                                                                          | [Before you edit: stop the app](recording-results-and-playoffs.md#before-you-edit-stop-the-app)                                                                                   |
| A new NHL season starts                                                             | Archive the current data file, repoint `DATA_FILE`/`--data-file` at a fresh path, restart                                                                                                  | The app bootstraps the new file with just `season` + an empty player list — everything else (players, teams, prediction sets) needs re-adding per the two first-deploy rows above |
| A new NHL season starts, and the running image is from a prior season               | Before rolling over, confirm the deployed image's `store.DefaultSeason` matches the real season — it's baked in at build time, so a stale image silently bootstraps the wrong season label | Ask whoever maintains the code to bump it and ship a new image first                                                                                                              |
| Any time                                                                            | Check the app's startup log for `malformed result` warnings after every edit                                                                                                               | [Reading the startup warnings](recording-results-and-playoffs.md#reading-the-startup-warnings)                                                                                    |
